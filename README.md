# Cig‑App — Compteur de cigarettes (PWA)

Application simple, rapide et installable sur iPhone/Android pour compter les cigarettes fumées dans la journée.  
Fonctionne hors‑ligne grâce au Service Worker et peut être ajoutée à l’écran d’accueil comme une vraie application mobile.

---

## 🚀 Fonctionnalités

- Compteur +1 / -1
- Sauvegarde automatique dans le navigateur
- Fonctionne hors‑ligne (PWA)
- Installation sur écran d’accueil (iOS / Android)
- Icône dédiée
- Interface simple, rapide et lisible

---

## 📱 Installation (iPhone / Android)

1. Ouvrir l’URL : **https://yessiledev.github.io/cig-app/**
2. Appuyer sur **Partager**
3. Choisir **Ajouter à l’écran d’accueil**
4. L’application apparaît comme une vraie app
